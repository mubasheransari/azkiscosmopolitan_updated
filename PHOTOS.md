# Adding real photos

Every card/page below shows `<name>.jpg` if the file exists, and automatically falls back to the
illustrated `<name>.svg` if it does not. **Just drop the file in — no code change needed.**

Recommended: JPG, landscape 16:9, **1600 × 900 px or larger**, under ~400 KB (compress at squoosh.app).
Use photos you own or that are licensed for commercial use (e.g. Unsplash, Pexels, or your own site/project photos).
